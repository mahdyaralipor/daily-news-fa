# برنامه‌نویسی و هوش مصنوعی — شنبه ۱۷ اکتبر ۲۰۲۶ (۲۵ مهر ۱۴۰۵)

## مدل‌ها و انتشارها

- **Reflection Beam 1.0 (۱۷ اکتبر)** — اولین مدل وزن‌باز Reflection؛ ۵۰۱ میلیارد پارامتر (۲۳ میلیارد فعال)، پنجره یک‌میلیون توکن، مخصوص کدنویسی و ایجنت، تحت مجوز Apache 2.0. روی لپ‌تاپ جا نمی‌شود (کوچک‌ترین چک‌پوینت ~۲۸۰ گیگ) اما رایگان روی Ollama Cloud و از ۰٫۲۵/۱ دلار روی OpenRouter. — [AI Loadout](https://theailoadout.com/newsletter/2026-10-17/)
- **DeepSeek V4.1-Flash به چک‌پوینت 1017 ارتقا یافت** — بدون تغییر نام (deepseek-flash) و قیمت (۰٫۳۰/۱٫۲۰ دلار اوج، نصف در غیراوج). DeepSWE v1.1 از ۷۴٫۲ به ۷۷٫۰؛ Terminal-Bench 4.0 از ۳۱٫۲ به ۴۲٫۳؛ پاسخ‌های کوتاه‌تر. همزمان Search و Fetch API دیپ‌سیک برای همه باز شد: ۰٫۷۵ دلار به‌ازای هر هزار درخواست موفق، و تا ۱ نوامبر در Harness و Claude Code و Codex رایگان. — [AI Loadout](https://theailoadout.com/newsletter/2026-10-17/) ـ [Yahoo/Investing.com](https://tech.yahoo.com/ai/articles/deepseek-releases-ai-model-opens-150321283.html)
- **PrismML Bonsai 2** — وزن‌های تریتینگ: مدل ۹ میلیاردی با دید و ابزار و پنجره ۲۵۶K در فایل ۳٫۲ گیگابایتی برای لپ‌تاپ ۸ گیگابایتی؛ نسخه‌های ۲B (مگ ۹۱۱) و ۴B و ۲۷B هم هست. Apache 2.0. — [AI Loadout](https://theailoadout.com/newsletter/2026-10-17/)
- **Elorian Glimpse** — استدلال روی تصویر و ویدیو با زوم روی نواحی و بازبینی کلیپ‌های کوتاه؛ جلوتر از GPT-6 Astra در خواندن نمودار و شمارش، عقب‌تر در بقیه. ۰٫۶۰/۳ دلار، پنجره ۲۶۲K. — [AI Loadout](https://theailoadout.com/newsletter/2026-10-17/)
